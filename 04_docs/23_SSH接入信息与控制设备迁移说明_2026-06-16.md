```sshconfig

  HostName 192.168.66.196
  User fz
  Port 22

Host wvd-rk3588
  HostName 192.168.66.85
  User linaro
  Port 22

Host wvd-raspberry
```

```bash
ssh wvd-orangepi-c973 'hostname; date'
```

## SSH Key 迁移建议

新控制设备建议生成一把专用 key：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/wvd_ed25519 -C "wvd-control"
```

然后把公钥安装到各设备：

```bash
ssh-copy-id -i ~/.ssh/wvd_ed25519.pub fz@192.168.66.196
ssh-copy-id -i ~/.ssh/wvd_ed25519.pub linaro@192.168.66.85
ssh-copy-id -i ~/.ssh/wvd_ed25519.pub berry@192.168.66.210
ssh-copy-id -i ~/.ssh/wvd_ed25519.pub orangepi@192.168.66.206
ssh-copy-id -i ~/.ssh/wvd_ed25519.pub orangepi@192.168.66.133
```

如果使用专用 key，在 `~/.ssh/config` 每个 Host 下补充：

```sshconfig
  IdentityFile ~/.ssh/wvd_ed25519
  IdentitiesOnly yes
```

## 切换控制设备步骤

1. 新控制设备连接到同一局域网，确认能访问 `192.168.66.196:8080`。
2. 克隆或拉取仓库：

```bash
git clone https://github.com/RealityLoopAI/wireless_video_delivery.git
```

3. 配置 `~/.ssh/config`，用上面的 Host 别名逐台验证 SSH。
4. 优先安装 SSH key，避免后续每次输入密码。
5. 从接收端检查系统全局状态：

```bash
ssh wvd-receiver 'cd /home/fz/Desktop/wireless_video_delivery && pgrep -af "gemini_receiver|uvicorn|server.py"; ss -ltnp | egrep ":(8080|18080|50010|50011)"'
curl http://192.168.66.196:8080/api/status
```

6. 从各发送端检查 sender：

```bash
ssh wvd-rk3588 'pgrep -af gemini_sender'
ssh wvd-raspberry 'pgrep -af gemini_sender'
ssh wvd-orangepi-b439 'pgrep -af gemini_sender'
ssh wvd-orangepi-c973 'pgrep -af gemini_sender'
```

7. 如果需要停启 sender，优先使用工程已有脚本或当前进程对应的配置文件，不要混用其他设备配置。

## 安全注意

- 不要把明文密码、私钥、token 写进仓库。
- 当前文档只归档连接坐标和操作入口。
- 若控制设备要长期使用，建议在所有设备上启用 key 登录后禁用弱密码或至少定期更换密码。
- OrangePi 两台主机名相同，操作前必须核对 IP 和正在运行的配置路径。
