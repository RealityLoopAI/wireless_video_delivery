# 2026-05-11 收尾归档说明

## 1. 当前归档状态

本次归档覆盖 Gemini Wireless Video v3 当前接收端、Web 监控、Orbbec 兼容导出工具和配套文档。

当前主要能力：

- C++ 接收端监听 UDP 状态和 TCP 媒体流。
- Web 页面提供在线状态、RGB/Depth 预览和录制控制。
- NAS 录制生成 `rgb.mp4`、`depth.mkv`、`frames.csv`、`meta.json`。
- `frames.csv` 已追加 `packet_system_timestamp_us`、`rgb_system_timestamp_us`、`depth_system_timestamp_us`。
- `export_orbbec_delivery.py` 可把 segment 导出为下游 Orbbec 兼容目录。

## 2. 用户入口

接收端保留以下直接入口：

```text
05_tools/status_receiver.sh

```


## 4. 验证记录

本次收尾验证项：

- `bash -n 05_tools/*.sh`
- `python3 -m py_compile 05_tools/*.py 09_web_monitor/server.py 10_tests/simulate_sender.py`
- `cmake -S . -B 12_build -DGWV3_BUILD_RECEIVER=ON -DGWV3_BUILD_SENDER=OFF`
- `cmake --build 12_build -j4`
- 短录制生成 NAS segment。
- 对短录制执行 `export_orbbec_delivery.py <segment> --overwrite`。
- `ffprobe` 验证 RGB 为 H.264 MP4、Depth 为 FFV1 gray16le MKV、Depth 预览为 H.264 MP4。

## 5. 已知边界

- GitHub 仓库不包含 Orbbec SDK 实体文件。
- 发送端构建需要在香橙派 / ARM64 环境放置 Orbbec SDK 后执行。
- 当前未完成多小时长时间稳定性报告。
- Depth 逐帧 PNG 是离线可选导出，不作为实时主存储默认格式。
- 多相机统一 session 目前由导出层预留结构，当前实测样例为单相机。
