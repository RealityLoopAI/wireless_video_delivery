# 产品手册（小白版）

## 1. 这个系统是干什么的

这个系统把相机画面从发送端设备实时传到接收端设备。  
你可以把它理解为：一个“无线视频链路”。

链路流程：

`Gemini相机 -> 发送端编码 -> Wi-Fi网络 -> 接收端解码 -> 屏幕显示`

## 2. 你需要准备什么

- 一台发送端 Linux 设备（接 Gemini 相机）
- 一台接收端设备（Linux 或 Windows）
- 两端在同一个局域网里互通

## 3. 最简单用法

1. 先启动接收端。  
2. 在发送端执行一条命令并输入接收端 IP。  
3. 接收端窗口看到画面即成功。

## 4. 常见问题

### Q1: 接收端 IP 变了怎么办？

不用改代码，直接重新启动发送端时传新的 IP：

`bash 05_tools/start_sender_easy.sh 192.168.1.105`

### Q2: 为什么画面偶尔会卡一下？

无线网络抖动或接收端解码压力大时会出现短暂抖动，这是实时视频常见现象。

### Q3: 一个发送端能连几个相机？

当前版本是单相机架构，一个发送端实例只支持一个相机。

## 5. 当前版本边界（先记这三条）

- 单发送端：`1` 个摄像头
- 多设备接入同一接收主机：建议按 `5` 台规划，`6` 台为上限
- 当前接收端核心是软件解码，不是硬件解码
