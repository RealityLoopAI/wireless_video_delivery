
发送端依赖 Orbbec ARM64 SDK，SDK 实体不进入 GitHub 仓库。当前 RK3588 现场配置使用 `sender_id: orangepi5pro-66-133`，接收端地址 `192.168.66.196`，基础双路配置为 `06_configs/sender_rk3588-01_two_cameras.json`；如需录制后由接收端脚本生成 RGB 坐标系下的 aligned depth，应使用 `06_configs/sender_rk3588-01_two_cameras_align.json` 并在录制前运行 `05_tools/check_sender_alignment_ready.sh` 确认 `calibration_available=true`。运行中支持配置外 Orbbec 设备热插拔，自动分配 `cam03` / `cam04`，最多同时发送 4 路。2026-05-29 现场实测结论：当前 Wi-Fi/接收端组合下稳定上限按 2 路满规格处理，3 路可运行但会出现 media TCP 背压丢包；详见 `04_docs/06_发送端运行使用手册_v3.md`。
