# lubancat-e8cc0cb3 实时音频推流部署

日期：2026-08-20

## 配置

- 发送端：`lubancat-e8cc0cb3`
- 目标：`192.168.66.32:50032/UDP`
- 协议：RTP/Opus
- 采样率：`48000 Hz`
- Opus 码率：`32000 bit/s`
- Payload Type：`111`
- SSRC：`3322710864`

`50032` 与 `lubancat-52d2ef0c` 的 `50030`、`orangepi5pro-d12a4719` 的 `50031` 分离，便于下游同时接收三路音频。

## 兼容行为

- 保留本机关键词唤醒、TTS 和拍照流程。
- 保留该设备已有的唤醒后整句 HTTP 转发配置。
- 播放本机提示音时不暂停实时 RTP 推流。
- 使用 `SM15 M1 USB audio` 作为输入和输出设备。
