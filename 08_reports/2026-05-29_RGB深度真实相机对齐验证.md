# 2026-05-29 RGB/Depth 真实相机对齐验证

## 结论

本次真实相机验证中，`RGB 640x480 + Depth 640x400` 组合具备完整 Orbbec 标定，离线生成的 `depth_aligned_to_rgb` 结果有效。RGB 画面、伪彩 aligned depth 和叠加图中的桌面、笔架、背包、立杆轮廓基本一致，可作为当前下游工程师验证样例。

`RGB 1920x1080 + Depth 640x400` 的早期测试不能作为有效空间对齐样例，因为 SDK 返回的 RGB 内参为 0。当前代码已改为只有 RGB 内参、Depth 内参和 Depth -> RGB 外参均有效时才声明 `calibration.available=true`，离线脚本也会拒绝内参尺寸不匹配或 D2C 外参全 0 的数据。

## 已同步到代码的防护

提交 `59b7e1f Validate RGB-depth calibration before alignment` 已推送到 `origin/main`。该提交包含：

1. 发送端优先读取当前 RGB/Depth profile 对应的 Orbbec 标定。
2. 发送端在内参或 D2C 外参不完整时不再声明 `calibration.available=true`。
3. 离线脚本 `05_tools/align_depth_to_rgb.py` 校验 RGB/Depth 内参尺寸必须匹配当前视频/profile。
4. 离线脚本拒绝 D2C 外参缺失或全 0 的 segment。
5. 文档已补充有效标定和离线对齐限制。
