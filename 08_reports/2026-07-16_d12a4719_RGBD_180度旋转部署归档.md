# d12a4719 RGBD 180 度旋转部署归档

## 需求

`orangepi5pro-d12a4719/cam01` 因物理安装方向改变，从本次部署起需要同时将 RGB 和 Depth 旋转 180 度，其他发送端不受影响。

## 实现

- 新增每相机可选配置 `rotation_degrees`，仅允许 `0`、`90`、`180`、`270`。
- 仅 `orbbec_sdk` 采集后端可以使用该配置。
- 发送端在启动 pipeline 前通过 Orbbec SDK 设置：
  - `OB_PROP_COLOR_ROTATE_INT`
  - `OB_PROP_DEPTH_ROTATE_INT`
- 先检查 RGB/Depth 两个属性均可写，设置后再读回验证。任一路失败时回滚已设置属性，避免两路方向不一致。
- `camera_announce` 增加 `rotation_degrees`，接收端会随 `camera_announce_raw` 保留到录制元数据。
- 该方案使用设备/SDK 旋转，不在 CPU 上对 RGB 或 Depth 进行逐帧拷贝。

## 设备配置

`06_configs/sender_orangepi5pro-d12a4719_gemini305.json`：

```json
"rotation_degrees": 180
```

## 部署和验证

- 部署设备：`192.168.66.133`。
- 备份目录：`/home/orangepi/Desktop/wireless_video_delivery_backup_rotation_20260716_161238`。
- ARM64 设备本机编译成功。
- 配置校验成功。
- SDK 启动日志：

```text
stream rotation set camera_id=cam01 degrees=180 color=true depth=true
```

- 发送端服务保持 `active/running`，接收端中 RGB 和 Depth 均持续更新。
- 接收端的新 `camera_announce_raw` 已包含 `"rotation_degrees": 180`。

## 现场 USB 状态

部署时 Gemini 305 枚举为 `USB2.1`，`lsusb -t` 显示 `480M`；SDK 在旋转前后都实际选择 `848x530@10` 的 RGB/Depth 档位。这是 USB 链路降速造成的已有状态，与 180 度旋转无关。要恢复配置的 30fps 档位，需要让该相机重新枚举到 `5000M/USB3` 链路。
