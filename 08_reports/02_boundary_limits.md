# 项目边界与容量说明

## 1. 发送端边界

- 当前代码架构：单发送实例单相机
- 单设备发送端建议上限：`1` 个摄像头

## 2. 接收端并发边界（当前实现）

- 推荐稳定规划：`5` 台发送设备并发
- 可冲刺上限：`6` 台
- `7+` 台进入明显不稳定区间

## 3. 网络侧边界

- 5GHz 条件下，网络一般不是首要瓶颈
- 实际端到端上限通常由接收端解码与渲染能力决定

## 4. 接收端换IP配置说明

- 正常只需改发送端目标 IP
- 推荐直接用命令传入，不手改 JSON：  
  `bash 05_tools/start_sender_easy.sh <receiver_ip>`
