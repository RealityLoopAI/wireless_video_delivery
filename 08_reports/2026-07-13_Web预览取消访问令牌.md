# Web 预览取消访问令牌

日期：2026-07-13

## 问题

提交 `863d5a1` 为 Web Monitor 增加了强制随机令牌、登录 Cookie 和 API 鉴权，导致采集局域网内首次打开预览页面必须输入令牌，与现场原有使用方式不一致。

## 处理

- 删除 Web Monitor 的登录页面、Cookie 和 `/api/*` 鉴权中间件。
- 启动及自启动脚本不再生成或注入 `GWV3_WEB_AUTH_TOKEN`。
- 保留 C++ receiver admin API 仅监听 `127.0.0.1:18080` 的限制。
- Web Monitor 继续监听配置中的局域网地址和端口，默认端口为 `8080`。
- 更新集成测试和部署、接口、故障排查文档。

## 验证

- `bash -n`：启动及自启动脚本通过。
- `py_compile`：Web Monitor 与集成测试通过。
- `receiver_hardening_integration`：通过。
- 接收端部署后，无 Cookie、无 Authorization 请求头访问 `/` 和 `/api/status` 均返回 HTTP 200。
- 只重启了 `gwv3-web-monitor.service`，未重启媒体接收服务。

## 使用边界

当前 Web Monitor 包含录制控制接口，只适合运行在受信任的采集局域网内，不应直接映射到公网。历史报告中关于强制令牌的内容由本次调整取代。
